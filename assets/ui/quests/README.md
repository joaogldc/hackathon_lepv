# HUD de quests

`mapa-de-descobertas.png` é o mockup gerado por IA, com 12 quests, nível e XP ilustrativos. O nome do bosque foi atualizado para **Bosque da Sabedoria**, mantendo os demais textos e elementos visuais.

O kit e a montagem completa estão em `artwork/porto-glacial-ia/`. Para uma interface dinâmica, os estados das quests, textos e barra de XP precisam ser conectados a controles e dados do jogo; os valores desta imagem são visuais.
