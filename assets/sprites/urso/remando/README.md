# Urso no bote — poses de remada

Gerado pela ferramenta integrada de imagens, usando os sprites reais da main
do GitHub como referências: E_sit.png, SE_idle_1.png e S_idle_1.png, em
assets/sprites/urso/frames/. A consulta foi feita pela extensão do GitHub.

Arquivo: urso_bote_remando_v1.png, RGBA, 1774 × 887, com transparência real.
Oito poses em duas linhas, da esquerda para a direita: alcance, entrada do
remo, início da puxada, puxada, final da puxada, saída e recuperação.

Esta é a arte das poses. Os recortes e pivôs ainda precisam ser ajustados
para montar uma animação sem deslocamentos no Godot. A imagem não tem uma
grade com dimensões inteiras uniformes; não assumir Hframes/Vframes como
registro final. Nenhum asset antigo foi substituído.

O prompt integral está em prompt_v1.txt.
