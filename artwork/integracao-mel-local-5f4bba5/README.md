# Integração local de mel recebida

Cópias integrais recebidas pela main até o commit 11f7331. Foram preservadas
para integração futura, junto dos recursos, animações e cenas originais que
continuam em suas pastas no projeto.

Esta versão usa a carteira local DailyJournal e o arquivo sequencia_mel_v1.tres.
O jogo atual usa Progress no servidor para inventário, saldo, XP e diárias.
Por isso o lobby em execução mantém a integração validada do servidor; o
código de demonstração recebido fica aqui, sem ser carregado pelo Godot.
Não é necessário mover esses arquivos para jogar em outro computador.
